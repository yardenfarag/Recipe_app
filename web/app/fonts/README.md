# Hebrew fonts

Google Fonts' Hebrew-only subsets (variable weight), self-hosted so they can be limited to Hebrew letters
(see `app/layout.tsx`):

- `heebo-hebrew.woff2`: [Heebo](https://fonts.google.com/specimen/Heebo), weights 100–900, for body text.
- `rubik-hebrew.woff2`: [Rubik](https://fonts.google.com/specimen/Rubik), weights 300–900, for headings.

Both are under the [SIL Open Font License 1.1](https://openfontlicense.org).
